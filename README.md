# FlexHub releases

Downloads and issue tracker for **FlexHub**, the macOS app that saves the windows on a screen as a snapshot and flexes them back with one click or shortcut.

## Download

Get the latest DMG from **[Releases](https://github.com/dungngminh/flexhub_release/releases/latest)**, open it and drag FlexHub to Applications.

- Requires macOS 14 Sonoma or later and the Accessibility permission.
- FlexHub needs a license key, sent by email after checkout. One key covers 1, 2 or 3 Macs depending on the tier.
- FlexHub checks this page for new versions. Settings › General › Updates checks on demand.

## Report a problem or ask for a feature

[Open an issue](https://github.com/dungngminh/flexhub_release/issues/new/choose). The fastest way is **Report an Issue…** in FlexHub's menu bar menu or in Settings › General: it fills in your FlexHub and macOS versions.

Please don't post your license key in an issue.

This repository holds releases only; FlexHub's source code is private.
